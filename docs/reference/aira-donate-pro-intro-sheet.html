这版排掉了哪些「AI 味」

  • 标题改成「捐赠Pro」。原来那版是个句子（「开源免费，捐赠自愿」），读起来像在解释自己。现在标题只给名字，把「开源、免费、自愿」交给下面两段事实去说。
  • 仓库入口是纯文字链接，不是按钮。页脚已经有一个主按钮和一个次动作，再放一个按钮会变成三选一。它也不加「开源」两个字重复标题，只写去哪。
  • 勾选图标 → 删。两段清单本来就是在陈述事实，不是「功能对比表」，打勾会把它们读成待办事项。同时删掉那 22px 图标列，两段清单的文字左边界现在完全对齐。
  • 字号从 5 档收到 3 档：32 / 17 / 13。标题 32，正文一律 17（含组标题、导语、清单），页尾备注 13。原来 16 和 17 混用是左边界错位之外另一个「看着不齐」的原因。
  • ① ② ③ 带色编号圆点 → 删。换成 hairline 分隔的普通行，编号本身就是模板感最强的元素。
  • 字距拉开的微标题 → 删。组标题就是一行 17px 半粗正文，靠字重和间距区分，不靠全大写 + letter-spacing。
  • 虚线描边卡 → 删。那一段已经压成页尾一行 13px 灰字。
  • 页脚渐变遮罩 → 换成 hairline 顶边。渐变是网页语言，iOS 用一条 0.5px 分隔线。
  • 边框 + 圆角 + 阴影三层叠加 → 只留 hairline。内容靠分隔线组织，不靠容器。
  • 大字号 + 负字距建立层级。标题 32px / -0.034em，这是 iOS 大标题的标准做法，比加色块更「贵」。

行为与待定

  • 只弹一次。第一次进入「捐赠Pro」页时弹出；点主按钮、点「以后再说」、或下滑关掉，都记为已看过，之后不再出现。
  • 仓库地址不写死。用现成的 `AIRA_COMMUNITY_REPOSITORY_URL`（`common/constants/AiraCommunityProjectLinks.ets`），跳转走应用已有的外部导航，不在 Sheet 里另开一套。
  • 名字范围待定。建议只把会员页与购买流程改叫「捐赠Pro」；《Aira Pro 会员服务协议》《自动续费服务协议》这类法定名称保持不动。
  • 「不限次数」待确认。现在客户端策略是「会员期内不能再领，到期可再领」，页尾那句是准的；如果服务端以后加冷却期要跟着改。
  • 免费领取的落点。页尾那句指的是页面上已有的领取入口，Sheet 里不重复实现流程。
